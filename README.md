# anishbadhri.github.io

Personal portfolio for **Anish Badri R S** — Senior Software Engineer, Google Workspace.

Static site built with [Eleventy](https://www.11ty.dev/) and styled with
[**@primer/primitives**](https://www.npmjs.com/package/@primer/primitives)
(GitHub's Primer design tokens, pulled in as an npm dependency). It ships as
plain HTML with **zero client-side JavaScript**, light/dark theming driven purely
by the system preference, and the critical CSS inlined into `<head>`.

---

## Quick start

```bash
npm install      # install dependencies
npm run serve    # local dev server with live reload → http://localhost:8080
npm run build    # production build → ./_site
```

Requires Node 20+ (see `.nvmrc`).

## Project structure

```
src/
  _data/
    site.js        # name, role, contact, social, SEO defaults
    resume.js      # experience, projects, skills, education, highlights
    css.js         # compiles + prunes + minifies CSS at build time
  _includes/
    base.njk       # HTML shell: meta, Open Graph, JSON-LD, inlined CSS
  styles/
    main.css       # imports Primer tokens (dependency) + local layers
    base.css       # reset, accent tokens, typography, a11y primitives
    layout.css     # header, container, section rhythm, footer
    components.css # hero, experience, projects, skills, contact …
  assets/          # favicon, og-image, résumé PDF (copied as-is)
  index.njk        # the page, assembled from _data
  sitemap.njk · robots.njk · 404.njk
.github/workflows/deploy.yml   # build + deploy to GitHub Pages
scripts/og-image.py            # regenerate the Open Graph image
```

**All content lives in `src/_data/`** — edit `resume.js` and `site.js`, never the
templates. (This separation is also what keeps a future move to Astro cheap.)

## Deployment (GitHub Pages)

This deploys via GitHub Actions, not the classic "deploy from branch" flow.

1. Create a repo named **`anishbadhri.github.io`** and push this code to `main`.
2. In **Settings → Pages → Build and deployment → Source**, choose
   **GitHub Actions**.
3. Every push to `main` runs `.github/workflows/deploy.yml`, which builds the
   site and publishes `_site`. Your site goes live at
   `https://anishbadhri.github.io/`.

No secrets or extra configuration are needed.

## Customizing

### Content
Edit `src/_data/resume.js` (work, projects, skills, education, highlights) and
`src/_data/site.js` (name, role, contact, social links, meta description).

### Résumé PDF
The download button serves `src/assets/anish-badri-resume.pdf`. **The current
file is your uploaded CV, whose title still reads "Software Engineer" rather than
"Senior Software Engineer."** Replace the file (keep the same name) to update the
download — no code change needed.

### Profile photo
The photo is intentionally **not shown on the page**. It is referenced in two
places only: the `Person` structured data (`site.photo`) and the Open Graph
image. To add your real photo:

1. Drop a square image at `src/assets/profile.jpg`.
2. Regenerate the share image with your photo:
   ```bash
   pip install Pillow
   # set USE_PHOTO = True at the top of scripts/og-image.py, then:
   python scripts/og-image.py
   ```
   (The `Person.image` URL in the schema already points at
   `/assets/profile.jpg`, so that updates automatically.)

### Open Graph / share image
`src/assets/og-image.png` (1200×630) is generated by `scripts/og-image.py`.
Re-run it after changing your name/title, or replace the PNG directly.

### Accent colour
The single custom colour sits in `src/styles/base.css`:

```css
:root { --accent: #642ab3; }                 /* light mode */
@media (prefers-color-scheme: dark) {
  :root { --accent: #b69eff; }               /* dark mode  */
}
```

Both values are contrast-checked against Primer's canvases (~7.8–8.4:1 → WCAG
AAA for link-sized text). If you change them, keep both modes above 4.5:1 (ideally
7:1). Update the matching colours in `scripts/og-image.py` and
`src/assets/favicon.svg` to keep the brand consistent.

## How it stays fast & accessible

- **Zero JavaScript.** Nothing to parse or execute; light/dark resolves through
  `prefers-color-scheme` in CSS (Primer's `auto` colour mode).
- **No web fonts.** Uses Primer's system-font stacks, so no font downloads and no
  layout shift.
- **CSS is inlined, pruned, and minified.** Primer declares ~1,100 design tokens;
  the build keeps only the ~200 this page actually uses (`src/_data/css.js`),
  then minifies — the inlined stylesheet is ~10 KB (~7 KB gzipped for the whole
  page).
- **Semantic + accessible.** Landmark elements, a skip link, a single `h1` with a
  logical heading order, visible keyboard focus, `prefers-reduced-motion`
  support, and AA/AAA colour contrast throughout.
- **SEO.** Canonical URL, descriptive title/meta, Open Graph + Twitter cards,
  `sitemap.xml`, `robots.txt`, and `Person` / `WebSite` / `ProfilePage` JSON-LD.

## Future enhancements (wired for later)

### Blog
Add a `src/posts/` folder with a Markdown collection and a `post.njk` layout,
then a `/blog/` index page. The data-driven setup leaves room for this without
restructuring.

### Moving to Astro
Low-to-moderate effort, by design. Content already lives in plain data files, so
migration is mostly translating the Nunjucks templates to `.astro` components and
pointing Astro at the same data. The Primer-token CSS and the assets port
unchanged, and the deploy workflow only needs its build command swapped.

### Lighthouse CI (optional quality gate)
Add `.github/workflows/lighthouse.yml`:

```yaml
name: Lighthouse
on: [pull_request]
jobs:
  lhci:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version-file: .nvmrc, cache: npm }
      - run: npm ci && npm run build
      - run: npm install -g @lhci/cli@0.14.x
      - run: lhci autorun --collect.staticDistDir=./_site --assert.preset=lighthouse:recommended
```

Tune assertions to taste; treat it as a PR gate once you're happy with the budget.
